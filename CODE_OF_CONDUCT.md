# Code of Conduct

## The short version

Be decent to people. Assume good faith. Argue about the code, not the person
writing it.

## The project-specific rule

This tool guesses at whether software was AI-generated, and it is wrong a
meaningful share of the time — which is why the interface says so before it says
anything else.

**Do not use this project's spaces to accuse anyone of anything.**

Concretely, the following will be closed and, if repeated, will get you removed:

- Opening an issue to report that someone else's site or code is "obviously
  vibecoded".
- Posting another person's work with a screenshot of its score, in a way that
  invites judgement of them.
- Using scores from this tool to support an accusation about a student, a
  candidate, an employee or a contractor.

If you are here because you want to catch someone, this is the wrong tool and the
wrong project. The reference this is built on is blunt about it: the practically
important question is almost never *"was a machine involved?"* but *"does anyone
understand this system and can they secure it?"*

Discussing your **own** code, or a public site **with the owner's involvement**, is
entirely fine and is how the detector improves.

## Expected behaviour

- Take a wrong reading as information, not as an insult.
- Accept that "inconclusive" is frequently the correct answer.
- Give people the benefit of the doubt about their intent.
- Respect that not everyone writes English as a first language. Text detectors are
  documented to be biased against non-native writers, and that bias has no place in
  how we treat each other either.

## Unacceptable behaviour

- Harassment, insults, or personal attacks.
- Discrimination or demeaning comments about anyone.
- Publishing private information without permission.
- Sexualised language or imagery.
- Sustained disruption of discussions.

## Scope

Issues, pull requests, discussions, commit messages, and any space where someone is
representing the project.

## Enforcement

Report a problem to the maintainer at **contact@fanficnow.com**, or privately via
[GitHub Security Advisories](https://github.com/goldo9824/vibecode-detector/security/advisories/new)
if you would rather it stay off the public tracker.

Reports are handled privately. The reporter's identity is not shared with the person
reported. Responses range from a warning to a permanent ban, depending on severity
and whether it happened again.

Maintainers who do not enforce this in good faith may themselves face consequences
decided by the rest of the project.
